A newspaper front page summing up the world's news of Monday 23 November 2026: Jensen Huang returns to Nvidia, Ukraine's war reaches Libya, the US blacklists Megaspeed, and more — rendered as one 1024×1024 image.

`generate.py` (Python + Pillow) draws the page and writes `entry.png`; `main.ts` copies it to the output directory the grader reads. The program runs twice and writes identical bytes.
